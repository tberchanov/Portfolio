# Portfolio · Kotlin Multiplatform

A cross-platform portfolio built with **Kotlin Multiplatform** and **Compose Multiplatform**, demonstrating expertise in modern development practices.

## Build & Run

| Target | Command |
|--------|---------|
| **Desktop** | `./gradlew :composeApp:run` |
| **Android** | `./gradlew :composeApp:installDebug` |
| **iOS** | `./gradlew :composeApp:syncFramework` |
| **Web** | `./gradlew :composeApp:wasmJsBrowserDevelopmentRun` |

---

**Note:** This project uses vibe coding - rapid prototyping and experimentation. Some code quality or structure decisions reflect this exploratory approach rather than production-ready patterns.
